## How I deliver automation

- **Map the process.** Identify inputs, owners, branching rules, expected outputs and failure paths before building.
- **Make data predictable.** Normalize records and validate structured AI output before it reaches downstream actions.
- **Test the whole workflow.** Check triggers, forms, payments, domains, routing and workflow exits before handover.
- **Keep operations visible.** Use integrity checks, execution monitoring, consolidated alerts and explicit manual-review paths.
- **Leave a maintainable system.** Document architecture, configuration, troubleshooting and handover steps.
